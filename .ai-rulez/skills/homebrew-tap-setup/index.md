# Concepts

* [Homebrew Tap Setup](SKILL.md) - Set up a new Homebrew tap by rendering copier-homebrew-tap with Copier, then configure repository naming (homebrew-<tap>), Actions settings, the producer dispatch token and bottle publishing through the pr-pull label, and hand the first formula or cask to homebrew-add and homebrew-verify. Use for new-tap bootstrap, for adopting the template in an existing tap, and for questions about copier copy or update, or why update PRs get no bottles unless the optional `WORKFLOW_TOKEN` is set.
