# Concepts

* [Homebrew Update Triage](SKILL.md) - Triage scheduled or release-dispatch Homebrew updates that fail, skip a release, or open a PR that did not build. Use for update-formulas.yml, update-casks.yml, update-formula-dispatch.yml and update-cask-dispatch.yml incidents, including livecheck that reports nothing, upstream renames, rate limits, bump-formula-pr or resource failures, audit or build failures, invalid dispatch payloads and update PRs without bottles; delegate repairs and finish with homebrew-verify.
